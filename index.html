01 / WHAT IT DOES

Less tab-hopping.
More building.

BRICKFORGE is a local bridge and browser extension that connects supported AI chat pages with Roblox Studio's MCP server.

⌘

AI to Studio

Connect ChatGPT, Claude, or Gemini in your browser to a Roblox Studio place through the local bridge.

⌁

Stay in flow

Start a session from the browser bar and work from your AI chat while BRICKFORGE handles the connection.

⬡

Roblox asset tools

Includes Roblox account linking and Open Cloud asset upload options, with credentials kept on your PC.

03 / GET STARTED

Three steps to launch.

Download the package, extract it, and follow the included setup guide. BRICKFORGE is a ZIP package, not a one-click installer.

STEP 01

Download & extract

Download the ZIP and choose Extract All. Do not run start.bat from inside the ZIP.

STEP 02

Prepare Studio

Install Python 3.9+ if needed, open a Roblox Studio place, and enable Studio as an MCP Server.

STEP 03

Connect the extension

Run start.bat, load the extension folder through Chrome or Edge developer mode, then start a session on a supported AI site.
